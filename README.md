Welcome to Terra-Pong!, a refreshing, nature-themed reimagining of the classic arcade hit. Developed using the Godot Engine for Hack Club’s "Terra" YSWS event, this project reimagines Pong to have... cooler art ig. While the gameplay remains the exact same as Pong, the very high quality (fr) pixel art provided colour and stuff. It is fully web-playable as a zero-install HTML5 title—you can jump right into the action and enjoy the game instantly on itch.io at https://n4th4ni3l.itch.io/terra-pong.

![Terra Pong's Icon](/Art/terra-pong.png)

How to play it: js click on the link  https://n4th4ni3l.itch.io/terra-pong    and press the play button.
